## 🚀 Getting Started

### Local Setup
1. Clone this repository
```bash
git clone https://github.com/Jothi2903/portfolio.git
cd portfolio
```

2. Open in browser
```bash
# Simply open index.html in your browser
# Or use a local server:
python -m http.server 8000
# Visit http://localhost:8000
```

### Deployment on GitHub Pages
1. Go to repository settings
2. Under "Pages" section, select source as "main" branch
3. Your site will be live at `https://username.github.io/portfolio`

## 📝 How to Update

### Add a New Project
Open `index.html` and find the `#work` section, then add:
```html
<div class="project">
    <div class="project-header">
        <h3>Your Project Name</h3>
        <a href="project-link" target="_blank" class="project-link">
            Live demo <i class="fas fa-arrow-up-right-from-square"></i>
        </a>
    </div>
    <div class="project-meta">Timeline | Company</div>
    <p>Description of what you built and the impact.</p>
    <div class="tech-tags">
        <span class="tech-tag">Technology 1</span>
        <span class="tech-tag">Technology 2</span>
    </div>
</div>
```

### Add Experience
Find the `#experience` section and add:
```html
<div class="exp-item">
    <div class="exp-date">
        <div class="exp-date-title">Month Year</div>
        <div class="exp-date-role">Your Role</div>
    </div>
    <div class="exp-content">
        <h3>Company Name</h3>
        <p>Description of your role and achievements.</p>
    </div>
</div>
```

### Update Skills
Find the `#skills` section and modify the skill categories as needed.
